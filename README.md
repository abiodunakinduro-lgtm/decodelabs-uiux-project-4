## Fresh From the Earth — Living Prototype

**From static screens to a living, interactive shopping experience.**

Fresh From the Earth is a premium organic grocery delivery mobile app designed to make discovering, selecting, and purchasing fresh produce simple, intuitive, and engaging.

This project continues from Project 03, where the core interface was established through the Splash, Listings, and Product Detail screens. Project 04 focused on transforming those designs into a high-fidelity interactive prototype through navigation, motion, micro-interactions, feedback states, and a complete shopping journey.

## 🎯 Project Goal

The goal was to turn the static interface from Project 03 into a connected and interactive shopping experience.

The prototype demonstrates:

* Smooth navigation and transitions
* Smart Animate interactions
* Micro-interactions and system feedback
* Product quantity controls
* Add-to-cart feedback
* Cart and order summary updates
* Delivery address selection
* Payment selection
* Complete checkout and order success flow

## 🧩 Design Process

**1.  Review** — Reviewed the Project 03 screens and identified what was needed to extend the experience into a full shopping journey.

**2.  Plan** — Mapped the main user flow from discovery to checkout and defined the required screens, states, and interactions.
   
**3.  Design** — Extended the existing visual system to create the Home, Search, Cart, Checkout, and Order Success screens.

**4.  Prototype** — Connected the screens in Figma using Smart Animate, Interactive Components, Overlays, and prototype transitions.

**5.  Refine** — Added micro-interactions, feedback states, quantity changes, cart updates, and smooth transitions.

**6.  Validate** — Tested the prototype flow to ensure users could move from product discovery to successful checkout without friction.


## ✨ Key Interactions

**Smart Animate**

Major screen transitions use Smart Animate (300ms, Ease In/Ease Out) for a consistent and smooth motion experience.

**Add to Cart**

Users can add products from both Listings and Product Detail.

Flow: Tap → Slide Up → Green Check → Confirmation → Auto Dismiss (approx. 1500ms)

**Quantity Controls**

Users can increase or decrease product quantity (1kg → 2kg → 3kg). The cart and order summary update accordingly.

**Order Summary**

The prototype demonstrates dynamic changes to quantity, subtotal, delivery cost, and total.

**Delivery & Payment**

Users can switch between Home and Office addresses and select a payment method before placing an order.


## 🧭 Happy Path
